# Changelog

## [1.2.0] - 2026-10-26

- Print preview: the thumbnail of the current print in every shelf row and in the done alert.
- Filament slots: a row of color dots per printer for AMS and ACE Pro slots, with the active slot ringed and empty slots hollow. Hover a dot for material and remaining amount.
- Spoolman: link a spool to each printer and see its name and remaining grams on the shelf, with a warning when the current print needs more filament than is left.
- More alerts: first layer done, 10 minutes left and a temperature warning when the nozzle stays too cold. Every alert type can be switched off in the settings.
- Camera: a second shelf widget with the live picture of the current printer and a switcher for several printers. The stream only runs while the widget is on screen.
- Controls: pause, resume and stop a print from the shelf. Stopping and pausing always ask for confirmation first.
- Menu bar: every printer with state, percent and time left.
- Print history with statistics, a 7-day chart and the last ten prints, stored only on this Mac.

## [1.1.0] - 2026-10-26

- Klipper printers with Moonraker, such as Mainsail, Fluidd, Creality K1 or Sovol. Time left comes from the slicer estimate when the file has one.
- Anycubic Cloud for Anycubic printers in normal online mode, no LAN mode needed. Print Live reads the status from Anycubic Cloud with the web token of your account.

## [1.0.0] - 2026-10-26

- Live print progress next to the notch, with percent and time left.
- Shelf overview of every printer with state, file, time left, finish time, layers and temperatures.
- Notch alerts when a print is done, paused or fails.
- Print progress on Droppy's lock screen.
- OctoPrint, Bambu Lab and Anycubic printers over the local network, without any cloud.
- API keys and access codes stored in the Keychain.
- English, German, French, Spanish, Italian and Dutch.
